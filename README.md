# Python Learning Repository

This repository contains my Python learning materials, exercises, and small projects.  
The content is based on general programming practice and online resources, including structured exercises inspired by the 42 curriculum.

---

## Purpose

The goal of this repository is to:

- Improve Python programming skills
- Strengthen problem-solving ability
- Practice algorithmic thinking
- Build small, self-contained projects
- Prepare for data science and software development work

## Topics Covered

### Basics
- Variables and data types
- Conditions and loops
- Input and output

### Functions
- Function definitions and usage
- Scope and return values
- Recursion basics

### Data Structures
- Lists, dictionaries, sets, tuples
- Basic data manipulation

### Algorithms
- Sorting and searching
- Problem decomposition
- Complexity awareness (basic Big-O understanding)

### Object-Oriented Programming
- Classes and objects
- Methods and attributes
- Basic design principles

### File Handling
- Reading and writing files
- Working with file paths
